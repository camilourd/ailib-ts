# sigmoid

Compara la derivada analítica con la numérica en una tabla y reporta el error máximo.

```
node lab/sigmoid/run.ts
```

Genera la gráfica de σ y σ′ que usa la nota (`docs/teoria/redes/sigmoid.svg`):

```
node lab/sigmoid/plot.ts
```

Requiere Node ≥ 23.6 (ejecuta TypeScript directamente).
