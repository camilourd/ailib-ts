# tensor

Recorre un tensor 2×3, lo transpone y lo reordena, mostrando forma y strides en cada paso:

```
node lab/tensor/run.ts
```

Operaciones: suma un sesgo a un lote (broadcasting), multiplica una columna por una fila, hace un
producto matricial y reduce por ejes:

```
node lab/tensor/ops.ts
```

Requiere Node ≥ 23.6 (ejecuta TypeScript directamente).
